# Security / public archive

This repository is a sanitized public archive of HHH Prototype 001.

- Production `.env` files are intentionally excluded.
- Database files and backups are intentionally excluded.
- SMTP, database, session, and API credentials are not included.
- Production deployment configuration is intentionally excluded.
- Demo credentials are supplied through environment variables only.

If a credential is ever discovered in this repository, revoke/rotate it immediately and remove it from repository history rather than merely deleting the current file.
