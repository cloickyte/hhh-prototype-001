# HHH Prototype 001

**Status:** Archived  
**Year:** 2026

Prototype 001 was the first public HHH experiment. It explored what happens when the decision of what someone should experience next is partially given to other people.

People could create spaces, host them publicly, and receive recommendations from others. This repository preserves the prototype as an historical artifact; active HHH development has moved beyond Prototype 001.

## Security

This is a sanitized public archive. Production `.env` files, databases, backups, deployment configuration, and credentials are intentionally excluded. See `SECURITY.md`.

Archive page: https://hhhorg.com/archive/prototype-001
